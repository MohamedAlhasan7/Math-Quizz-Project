# 🧮 Math Quizz Project

A console-based Math Quiz game built with **C++**.

The game allows the player to choose the number of questions, difficulty level, and operation type. It then generates random questions, checks the player's answers, and displays the final result.

---

## 🎮 Features

- 🔢 Choose the number of questions
- 📊 Choose the question difficulty:
  - 🟢 Easy
  - 🟡 Medium
  - 🔴 Hard
  - 🔀 Mix
- ➕ Choose the operation type:
  - ➕ Addition
  - ➖ Subtraction
  - ✖️ Multiplication
  - ➗ Division
  - 🔀 Mix
- 🎲 Random question generation
- 📝 Answer each question through the console
- ✅ Automatic answer checking
- 📈 Track correct and wrong answers
- 🏆 Pass / Fail result
- 🎨 Screen color changes based on the answer
- 🔄 Play again option
