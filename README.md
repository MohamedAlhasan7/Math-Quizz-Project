# 🧮 Math Quizz Project

A console-based Math Quiz game built with **C++**.  
The game allows the player to choose the number of questions, difficulty level, and operation type, then generates random questions and evaluates the player's answers.

---

## 🎮 Features

- 🔢 Choose the number of questions
- 📊 Choose the difficulty level:
  - 🟢 Easy
  - 🟡 Medium
  - 🔴 Hard
  - 🔀 Mix
- ➕ Choose the operation type:
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - 🔀 Mix
- 🎲 Random question generation
- ✅ Automatic answer checking
- 📈 Track correct and wrong answers
- 🏆 Pass / Fail result
- 🎨 Screen color changes based on the answer
- 🔄 Play again option
